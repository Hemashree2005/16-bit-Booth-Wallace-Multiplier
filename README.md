# 16-bit-Booth-Wallace-Multiplier
A 16-bit Fault-Tolerant Hybrid Booth–Wallace Tree Multiplier implemented in Verilog HDL and taken through the complete RTL-to-GDSII ASIC design flow. It combines Radix-4 Booth encoding, Wallace tree reduction, and concurrent error detection and correction, using Cadence Xcelium, Genus, and Innovus.
